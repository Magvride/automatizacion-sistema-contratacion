Los sitios son áreas de proyecto donde puede colaborar con otras personas, compartir contenidos y trabajar conjuntamente. Este dashlet presenta una lista de los sitios a los que usted pertenece. Puede aplicar un filtro a la lista para ver solamente sus sitios favoritos.

Desde aquí, puede:

  • Navegar hasta un sitio.
  • Crear un sitio nuevo.
  • Eliminar un sitio (si usted es administrador del sitio).
  • Marcar un sitio como favorito para que aparezca en el menú Sitios, para poder acceder fácilmente.

Este dashlet presenta una lista de las tareas que se le han asignado, incluyendo las invitaciones para unirse a sitios. Puede aplicar filtros a la lista para ver distintos tipos de tareas.

Desde aquí, puede:

  • Editar una tarea para gestionarla.
  • Ver una tarea específica.
  • Abrir la página Mis Tareas para gestionar todas sus tareas.
  • Iniciar un flujo de trabajo para crear tareas para otras personas o para usted.

x

Con este dashlet, es fácil hacer un seguimiento de sus sitios. Presenta las actividades de todos los sitios a los que usted pertenece, como los contenidos que se han añadido, eliminado o modificado. También podrá ver quién se une a sus sitios o los abandona.

Con los filtros, podrá ver las actividades por período y por propiedad.

Si no ve la lista completa de actividades del periodo o propietario que ha seleccionado, puede que su equipo de TI haya impuesto un límite en el número de actividades a mostrar.

Con este dashlet, podrá realizar cómodamente un seguimiento de sus contenidos, independientemente del sitio en que se encuentren. Utilice el filtro para encontrar fácilmente lo que busca.

Hay dos vistas para este dashlet. En la vista detallada, puede:

  • Marcar un elemento como favorito para que aparezca en las listas de favoritos, para facilitar el acceso.
  • Indicar que le gusta (o que no le gusta) un elemento.
  • Ir a la página de detalles del elemento para dejar un comentario.
